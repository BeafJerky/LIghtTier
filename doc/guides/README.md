## 收纳范围（示例）

- 双端打包指南（`src-tauri/lt-repack-all.ps1` 用法与产物说明）

- 开发环境搭建（Node / Rust / Android SDK 等）
- 使用手册与常见问题排障

## 不放什么

- 强制性规则 → `conventions/`
- 方案设计与取舍 → `design/`

## 约定

- 面向人：命令可直接复制执行，步骤可照做
- 有平台差异（Windows / Android）时分小节说明
