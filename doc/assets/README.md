# assets · 文档资源

> 用途：存放被文档引用的图片、截图、示意图等静态资源（预留文件夹）。推送：随仓库推送。规则「图片跟随文档」：只收被推送文档引用的图片；本地文档（`tracking/`、`local/`）的截图不要放这里。单图建议小于 500KB。

## 使用约定

- 文档内用相对路径引用：`![描述](../assets/文件名.png)`
- 命名：`<主题>-<序号>.<扩展名>`，如 `repack-01-artifacts.png`
- 大图先压缩再放入；与特定文档强关联的图片可放同名子目录
- 本地文档的图片随文档存放（`local/`、`tracking/` 内），**不要**混入本文件夹——会被一并推送
