# local · 本地专用（不入库）

> 用途：草稿、私人笔记、临时分析等**不打算推送**的内容。推送：不推送——本文件夹中只有 `README.md` 会随仓库推送，其余内容被根 `.gitignore` 忽略（规则：`doc/local/*` 与 `!doc/local/README.md`）。

## 规则

- 放进本文件夹的文件不会被 git 跟踪，可放心存放临时内容
- 结构化的问题跟踪 / 进度记录放 `tracking/`（同样不入库）
- 本地文档的图片 / 截图随文档存放，不要放进 `assets/`（会被推送）
- 需要长期维护或与协作者共享的文档不要放这里 → 按根 `doc/README.md` 的决策指引放入其他文件夹
- 密钥、令牌等机密信息不应写入任何文档（包括本文件夹）

## 常见内容

- 未成形的草稿与个人备忘
- 含本地环境路径、账号信息的临时记录
- 本地归档：完成但不打算公开的文档（可自建 `archive/` 子目录保持组织）
