# conventions · 开发规范

> 用途：收录**必须遵守**的开发规则类文档（约束性、可检查）。推送：随仓库推送——团队成员与 AI 协作均以这些规则为准。

## 收纳范围

- Git 提交与版本号规范（现有：`Git提交与版本号规范.md`）
- 代码风格与命名规范
- 主题变量与开发规范
- i18n 文案规范
- Tauri 权限与安全规范

## 不放什么

- 「怎么操作」的教程 → `guides/`
- 「为什么这样设计」的讨论 → `design/`

## 约定

- 文件名建议为 `xxx规范.md`
- 规范依据工程实际配置编写；**修改配置后必须同步修改对应规范文档**
